# Migration Reconciliation

One-time cutover reconciliation (record counts, control totals, trial balance, AR/AP,
inventory quantity and value, bank) comparing the ERPNext source against the iDempiere
target during a migration rehearsal or the real cutover (Phase 21–22). This is distinct
from `modules/reconciliation`, which is the ongoing *operational* reconciliation that
runs in production after cutover. Empty until there is a real migration to reconcile.
See `../README.md`.
